# 视觉精确定位

内部增强能力，供产品、交互、研发和测试按需复用。目标位置、边界或相对间距会影响结果时主动采用，无需用户再次要求。依据场景判断，不靠固定词命中，也不把所有看图升级成标注作业。

先看干净原图并确认像素尺寸、方向与当前状态；需要精确框选、添加元素、调整边界或解决偏移时，生成红色横竖坐标网格，再实际打开网格图。细小或密集目标结合局部放大。网格默认 100px，可缩小间距；目标以真实边界为准，不吸附网格。

```sh
open-vibecoding visual-grid --source /absolute/source.png --out /absolute/new-grid.png --step 100
```

CLI 输出原图尺寸与哈希，可用于后续定位计划。只写新 PNG，不改原图；网格是观察副本，不作为最终界面、设计参照或标注底图。

- 目标记录为原图像素 `[x,y,width,height]`。长截图、局部截图、缩放预览都要确认原点与比例，不能拿预览坐标直接点击屏幕或填写 CSS。
- 需要从缩放或裁切预览换回原图时，可用同一命令的 `--json-file` 传显式映射，合同见 [坐标换算](references/coordinates.md)。比例与裁切来源不明时重新取图或确认，不能猜设备像素比。
- 真正操作界面时，遵守宿主工具坐标合同。可靠的 DOM 或无障碍定位仍可优先用于操作，网格辅助肉眼核对；不借网格绕过工具的截图来源限制或窗口归属要求。
- 区分目标边界、容器中心和主体视觉重心；网格不能证明内容语义、光学居中或操作成功。已有对齐测量与 `visual-compare` 能完成的部分继续复用。
- 页面滚动、窗口变化、图片裁切、旋转或重新生成后，旧定位失效；更新截图并重新映射。实际修改保持最小范围，最终查看无网格结果与局部细节，检查周边内容是否误改。
- 只需观察时不输出用户标注，不创建固定报告。网格与裁切继承原图隐私，不自动上传；对外分享先处理敏感信息，再从同一安全副本派生。

需要把问题位置解释给用户时调用 `$open-vibecoding-image-annotation`。本能力不增加部署、发送、发布或修改产品的授权。
