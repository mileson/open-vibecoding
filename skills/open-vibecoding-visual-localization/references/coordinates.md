# 坐标换算合同

`visual-grid --json-file mapping.json` 可在生成网格的同时返回 `mappedTargets`，不执行点击或修改图片内容。先生成一次网格取得真实 `source`，再编写映射；以下数值仅用于解释字段。

```json
{
  "source": {"width": 1200, "height": 900, "sha256": "使用工具返回的原图哈希"},
  "view": {"width": 300, "height": 200, "crop": [100, 200, 600, 400]},
  "targets": [{"id": "target", "rect": [50, 40, 100, 30]}]
}
```

这里 `view` 是显示出来的图片内容矩形的宽高，不含浏览器工具栏、留白和外部边框。`crop` 表示该视图对应原图中的哪块区域；未裁切时省略它。示例映射回原图为 `[200,280,200,60]`。

换算是 `原图 x = 裁切 x + 预览 x × 裁切宽 / 预览宽`，y 同理。目标宽高按相同比例换算；不默默四舍五入或吸附网格。需要整数裁切时显式选择取整方式并检查边界。

工具校验源哈希、尺寸、矩形范围及等比例显示；旋转、透视、拉伸、拼图与留白不在此简单映射范围，必须先明确实际变换，不能假设平移缩放就足够。EXIF 方向异常需先另存标准方向副本，再重新看图与取坐标。

换算只解决已声明关系中的几何问题，不证明 Agent 看对了按钮，也不提供图片到屏幕或 DOM 的通用映射。Computer Use 的截图、缩放及操作坐标必须按当时工具返回的实际合同核对。
