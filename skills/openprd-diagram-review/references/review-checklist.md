# Diagram Review Checklist

Agent self-review checklist. Record unresolved items as attention; ask the user only when a real ambiguity would materially change the result:

1. Are any components or steps missing?
2. Are any boundaries, swimlanes, or ownership splits wrong?
3. Are any external dependencies missing?
4. Are any decision points, failure paths, or review/sign-off points missing?
5. Are any labels wrong or in the wrong language?
6. Is this complete enough to support the intended readiness claim, or should the diagram be revised in the background?
