# 轻量标注计划

先用 `visual-grid` 获取原图的 `source` 尺寸与哈希，并看图确定位置。`image-annotate` 不消费带网格的图，也不从预览猜原图位置。JSON 示例中的文字与数值是字段说明，实际任务须替换为当前原图信息。

```json
{
  "source": {"width": 1200, "height": 900, "sha256": "使用工具返回的原图哈希"},
  "fontSize": 20,
  "color": "#e62323",
  "protectedRegions": [[130, 115, 140, 24]],
  "targets": [
    {"id": "download", "rect": [110, 100, 190, 50], "kind": "single", "label": "点击下载"}
  ]
}
```

- `source` 必须绑定当前文件，防止截图变化后复用旧坐标。所有矩形均为 `[x,y,width,height]` 原图像素。
- `protectedRegions` 填所有不能遮挡的文字与重要区域；包含目标按钮中的文字也合理，允许框包围文字，但实际框线不能穿过保护区。工具不执行 OCR，空数组不能证明图片没有文字。
- `targets` 为 1–64 项，每项稳定且唯一的 `id`、完整目标 `rect`、短标签 `label`。`kind` 支持 `single`、`sequence`、`alternative`，默认独立单点；顺序与字母按计划顺序生成，批次或章节单独作图。
- 默认在目标下、上、右、左依次尝试安全标签位置。需要明确锚点可填写 `labelRect`，但仍接受越界、距离、文字保护与碰撞校验。不会为排版挪动目标。工具使用保守字宽估计，实际字体仍需看图确认。
- `fontSize` 范围 12–96，默认 20；这是起点，不能证明在缩略图里可读。颜色支持显式 `#RRGGBB`，一张图保持一致。当前轻量工具使用相邻标签，不自动绘制跨越页面的箭头。
- 工具拒绝框线出界、标签与目标/保护区/其他标签重叠、过远标签及无安全布局。`layout_collision` 时改锚点、缩短文案或拆图；不能删除真实保护区来绕过检查。

只支持单帧 PNG、JPEG、WebP，最多 16M 像素、64MiB 文件。输出新的 PNG，拒绝覆盖已有目标；不添加源 EXIF 元数据，不改变尺寸、旋转或自动裁切。PDF、SVG、视频和动图先由对应工具转成明确帧或页面，再重新确定坐标。

CLI 输出的 `resolvedPlan` 可按复查需要保存，不强制落盘报告。几何校验不能证明未标声明的文字安全、功能单元完整、许可有效或视觉体验通过。
