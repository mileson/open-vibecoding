# 画布协作

先判断画布是否比一段说明或小图更能帮助用户选择。若需要，绑定当前真实线程或会话，明确要讨论的对象、可编辑区域和需要反馈的问题；不能从旧任务画布静默继承结论。

- 将现有截图、流程或架构作为参考对象，标清事实、候选方案与用户批注。画布中的未确认选择不自动视为产品决定。
- 使用 `canvas` 能力时先核验当前宿主和绑定状态；无法可靠绑定时先说明，避免把反馈写进别的会话。
- 用户反馈形成决策后，只向相关产品、交互或研发子能力传递必要结果；不要把画布变成每项任务的必经审批节点。
- 外发、下载或持久化素材遵守用户范围和媒体安全规则。
