# 图标来源与选择依据

核验日期：2026-10-02。下面是候选渠道，不是自动匹配表；站点能力与许可使用时复核。页面创建/修改时间及访问、点赞、评论指标未提供，均为未知。优先级由用途相关性、原始来源和实际许可决定，不按图标数量排序。

| 渠道 | 适合的用途 | 获取与选择注意 |
| --- | --- | --- |
| [Phosphor](https://phosphoricons.com/) | 成套 UI 操作、导航符号 | 先判断是否匹配项目已有家族；同组统一重量/变体，不因为“高质感”就替换现有图标。官网为 JS 页面，使用时检查实际详情与随资产附带的许可。 |
| [LobeHub Icons](https://lobehub.com/icons) | AI 公司、模型与产品品牌 | 官方页面提供 AI/LLM 图标目录及 SVG/PNG/WebP 静态资产说明；变体依图标而异。检查品牌对象、明暗及单色/彩色版本，不把 logo 改造成产品功能隐喻。官方文档：[icons.lobehub.com](https://icons.lobehub.com)。 |
| [TechIcons](https://techicons.dev/) | 语言、框架与开发工具标志 | 官网明确提供 SVG/PNG，并声明源素材来自 Devicon；以对应图标来源和品牌使用规范确认许可，不为统一色调破坏标志辨识。 |
| [Thiings](https://www.thiings.co/things) | 立体物件、功能插画、空态与较大入口 | 官方集合为 AI 生成 3D 图标；检查下载文件的 alpha、视角、光照与产品风格。[当前条款](https://www.thiings.co/terms) 免费个人下载限非商业且需署名，商业使用需匹配许可；不要将“免费”写成通用商用承诺。 |
| [iconfont](https://www.iconfont.cn/) | 功能符号、矢量与特色插画 | 以具体图标集和作者为单位选用，核对许可及实际下载格式；不同作者风格不能因同平台而当成同一套。官网部分内容依赖 JS；在线编辑与搜索入口按当前页面核实，不硬编码网页选择器。 |

项目已有 Lucide、Tabler、系统符号或其他家族时，先复用其可用图标，不为了增加渠道而增加依赖。渠道不足可以扩展本清单或增加独立 Skill；不要求用户完成素材搜集。
