# 图标多渠道检索

根据角色与风格挑选来源；来源建议见 [渠道清单](references/sources.md)。先看现有项目图标与组件，没有合适资产再检索。Agent 自己从用户动作、对象与结果理解语义，尝试同义概念和可识别视觉隐喻；不建立固定关键词触发器。

检索时优先找完整家族及风格变体，比较语义准确性、小尺寸识别、线宽/填充、圆角、颜色、留白和实现格式。不要因为单张图精致就把不同家族塞进同一排。第三方品牌使用真实标志，先查品牌自己的资产或核实站点所收录对象与变体。

使用当前可用搜索、网站浏览或官方素材入口取得实际文件，不虚构 slug、下载 URL 或不存在的搜索 API。需要网站操作时用任务专用浏览器；遇到登录、收费或网站不可访问，沿用当前授权与可用来源，不把“用户还没给图标”当成唯一解决路径。

核对候选详情、许可、来源更新信号与原始文件。免费预览或可下载不代表商用许可；未知许可标为未知，优先选已明确许可的替代。只获取本次需要的资产，不整库下载。下载 SVG 时检查外部引用、脚本及事件属性，避免把未知 SVG 当可执行 HTML 注入页面；复用已有组件或安全静态资源方式。

把真实文件或项目已有包中已确认的图标映射到消费位置，检查对应格式和主题变体。包/API 用法先读本地类型与文档，证据不足时按项目外部技术规则调研。接入后在真实尺寸看效果；交付来源、许可状态、变体、资产路径和未解决缺口。只有风格或语义确实不匹配时，再请求 SVG 或位图设计子能力。
