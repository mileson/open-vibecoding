# 路由与豁免

## 语义路由

先问“任务是否会改变真实媒体，或是否对真实媒体结果作出声明”，不要只匹配“音频”“字幕”等词。

| 场景 | 是否使用本 skill | 原因 |
| --- | --- | --- |
| 调整降噪、响度、混音、静音、消音、哔声或导出 | 是 | 最终音轨可能改变 |
| ASR、转写、说话人、语言、分段或时间戳质量 | 是 | 声称语音派生结果的质量 |
| 根据转写自动剪辑、自动打码或生成字幕时间轴 | 是 | 文字决策会作用到真实媒体 |
| 检查 SRT/VTT 是否写入最终视频并与声音同步 | 是 | 需要验证最终媒体和时间关系 |
| 修正一处人工字幕错别字 | 否 | 不涉及语音识别或媒体质量声明 |
| 把已经确认的字幕翻译成另一种语言 | 否 | 这是语言质量任务；除非同时声明音轨对齐或最终渲染 |
| 修改字幕字体、颜色、字号、位置或编辑器预览 UI | 否 | 走视觉证据；除非同时改时间轴，或检查已经导出/烧录的最终媒体 |
| 编写一段 AI 口播稿但不处理录音 | 否 | 只处理文本，不是 ASR 或媒体证据 |

同时包含多类工作时拆分声明。例如“翻译字幕并重新烧录视频”中，翻译质量可以人工审校，最终渲染与音画同步仍进入媒体证据链。

## 合法豁免

以下情况不触发媒体证据链，只有边界容易混淆时在对话中说明原因：

- 任务只改文案、翻译、错别字或标点，没有基于语音作准确率声明。
- 任务只改播放器、字幕列表或字幕视觉样式，不改音轨、时间轴和最终媒体。
- 当前步骤只处理非媒体范围，且明确没有声称真实结果已经改善。

任务从未进入媒体证据链时，不创建 `openprd.media-evidence.v1` 空包。先判断声明是否适用：任务已经进入媒体证据计划、但后来确认证据包中的全部媒体声明均不适用时，使用证据包状态 `waived`；部分声明仍适用时拆分证据包。只要仍有适用声明但当前只有证据计划或修改前基线，就使用 `baseline-only`。

已进入媒体证据计划再豁免时，说明不触达的媒体边界、为什么不需要最终媒体复测和剩余风险。可直接在交接中表达，例如：

```text
本任务只修正已确认字幕文本，不改变 ASR、时间轴、音轨或最终渲染；媒体准确率与同步质量不在本轮声明范围。
```

不能用“没有工具”“没有样本”“来不及”作为完成态豁免。这些情况应写为 `blocked` 或 `baseline-only`，对应声明保持未知。

## 项目层与通用层

通用层只规定证据结构、比较原则和声明边界。产品自己的阈值、特殊词典、默认语言、引擎版本、设备差异和经过复发验证的失败模式留在项目层，并引用本 skill，不复制本工作流。
