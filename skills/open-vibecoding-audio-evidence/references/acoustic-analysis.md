# 声学、剪辑与混音分析

## 先确认媒体结构

记录容器、时长、音轨索引、编解码器、采样率、声道、时间基准和目标片段。多音轨媒体必须说明为什么选择这条音轨。若分析前发生重采样、声道合并或响度归一化，也要把它当成测量配置的一部分。

## 按声明选择指标

没有适用于所有产品的固定阈值。只选择能裁决当前问题的指标，并让基线与最终输出保持同一口径。

| 声明 | 可选机器证据 | 必要人工检查 |
| --- | --- | --- |
| 电平与动态 | integrated loudness、short-term/momentary loudness、sample/true peak、loudness range、crest factor | 目标片段是否自然，是否出现泵动、忽大忽小或听感失真 |
| 削波与失真 | clipped sample/event count、连续削波区间、峰值分布、DC offset | 边界是否刺耳，瞬态是否被破坏 |
| 噪声与可懂度 | noise floor、SNR 或代理指标、频带能量、语音/非语音区间 | 语音是否更清楚，是否引入水下声、金属声或呼吸门限 |
| 静音与连续性 | silence ratio、silence/dropout segments、突变点、音频存在性 | 开头结尾、切点、停顿是否符合语义，是否误删音节 |
| 混音与导出 | 轨间电平关系、声道关系、时长/起点/终点、音画漂移 | 人声与音乐/环境声关系、转场、设备播放表现 |
| 消音、哔声与自动剪辑 | 目标区间覆盖率、前后边界、未目标片段变化、遮蔽段能量 | 敏感词是否完整遮蔽，语义是否仍泄露，边界是否突兀 |

工具只能报告它实际支持的测量。若工具给出的是估算或代理指标，在证据包里保留方法、版本、参数和限制，不把代理值写成标准真值。

## 片段策略

至少保留：

- 能复现问题的代表片段。
- 问题前后各一段上下文，避免只测裁剪后的“好看窗口”。
- 容易回归的边界片段，如开头、结尾、切点、跨说话人或强弱音切换。
- 一个未目标区域，用于证明优化没有大范围破坏原音轨。

时间范围统一用秒并记录时间基准；界面显示帧号时同时保留帧率或媒体 timebase。

## 前后比较

最终输出必须重新探测媒体结构并重新测量。比较前确认：来源一致、目标音轨一致、分析窗口一致、增益/归一化策略一致、测量工具与参数一致。

如果最终输出改变了时长或时间轴，保存片段映射，不能直接比较错位窗口。报告指标差值时同时保留基线值、最终值、单位和方向；发现非目标区域回归时，状态不能写成无条件通过。

## 最小人工审听合同

项目层必须在比较前定义并写入 `manualReview`：试听增益或响度匹配策略、耳机/扬声器与播放环境、要判断的听感量表、接受规则，以及目标、边界和未目标控制片段。每个片段记录 `pass`、`fail` 或 `unknown` 与理由；“金属感”“水下感”“泵动”和可懂度不能只靠机器代理指标判定。
