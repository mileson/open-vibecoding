# FastAPI 端点检查清单

按接口行为选择相关条目。以契约、项目源码和已有测试为依据。

| 检查项 | 核对内容 |
| --- | --- |
| 接口与挂载 | 从应用入口核对完整路径、HTTP 方法、前缀和依赖。核对是否已挂载，以及与既有路径是否冲突。 |
| 请求与响应 | 对齐必填、默认值、别名和错误格式。局部更新按契约区分字段缺省与显式空值。请求仅接收允许写入的业务字段，响应仅公开契约允许的字段。 |
| 身份与权限 | 从项目现有依赖取得可信身份，核对角色或权限要求。按租户、所有者或资源授权范围执行读写，列表、计数、详情和变更使用对应的同一范围。按项目规则处理无匹配记录和无权限情形。 |
| 查询与分页 | 沿用项目的分页协议、上限和排序规则。对外开放的过滤项和排序字段来自明确允许范围。列表和计数使用相同的业务过滤条件。 |
| 写入与事务 | 复用项目的事务边界和失败恢复方式。避免在权限检查之前产生副作用。明确重复请求、并发冲突、软删除或物理删除中与契约相关的行为。 |
| 错误和文档 | 复用错误映射与日志惯例，响应不暴露内部异常或敏感字段。核对现有 OpenAPI 是否反映接口契约及相关文档可见性。 |

## 验证示例

- 列表端点使用有不同访问范围的测试身份，核对返回记录和总数都符合各自的可见范围。
- 更新端点验证合法变更、无权变更和契约允许的空值行为，读回数据确认校验失败或权限拒绝时记录保持原状。
- 注册新路径后用实际应用实例发请求，检查完整路径、成功响应和项目约定的错误响应。单独调用处理函数可辅助定位问题。
