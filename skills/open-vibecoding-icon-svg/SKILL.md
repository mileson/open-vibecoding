# 自定义 SVG 图标

先检查现有矢量与组件，选一枚代表性图标作为风格参照。明确对象、动作与消费尺寸；复杂语义先简化成可识别轮廓，再选择几何、描边或填充。品牌标志使用核实素材，不凭记忆重绘第三方 logo。

沿用家族的 viewBox、线宽、linecap/linejoin、圆角、光学尺寸和安全留白；图标使用可维护 path/基础几何，动态颜色按已有组件或 `currentColor` 约定。纹理丰富或立体材质图标交给位图能力，不把 raster 包进 `<image>` 后称为可编辑矢量。

保留真实孔洞与负空间，注意描边外扩和小尺寸细节消失。制作成组资产时共享基础笔画和构图逻辑；通过实际渲染逐个微调视觉重量，而非只统一外框宽高。SVG 中的 script、事件属性、外部资源和不必要嵌入不进入产品资产。

在实际消费尺寸以及产品使用的明暗背景上观察轮廓、对比、光学居中与同槽位对齐；检查控件状态和可访问性名称。交付源 SVG 或已有框架的图标组件，接入消费位置；必要的成套比较可用 `visual-compare`，不创建固定文档。
