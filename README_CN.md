# Open VibeCoding

面向 Vibe Coding 的能力增强型协作框架（Harness），让 Vibe Coding 看得见，可审查、可学习、可进化。

[快速开始](#readme-section-1) · [进一步阅读](#readme-section-2) · [仓库导航](#readme-section-3)

<a id="readme-section-1"></a>

## 快速开始

项目命令定义在 [`package.json`](package.json)。

常用入口：

| 命令 | 用途 |
| --- | --- |
| `npm run start` | 启动服务 |
| `npm run test` | 自动化测试 |

执行前先安装与锁文件对应的依赖，并按项目文档补齐环境配置。
