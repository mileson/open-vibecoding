# OpenPrd 0.2.3

## 安装

```bash
npm install -g @openprd/cli@0.2.3
```

## 本次更新

- 新增：复杂任务进入人工审查节点时，Agent 会主动判断并制作任务专属 HTML 审查页。
- 优化：OpenPrd 只提供触发条件、证据结构和验证标准，页面结构、视觉与实现由 Agent 根据任务自行决定。
- 优化：不强制固定模板或渲染器，避免所有任务被套进同一种通用页面。
- 修复：Markdown、CSV、占位页或仅创建 HTML 文件不再被视为完成；审查页必须使用真实证据、给出可打开路径并完成结构与语法验证。
- 验证：新增生成式引导一致性回归，并通过独立盲测确认 Agent 在没有收到 HTML 指令时仍能按任务需要主动产出审查页。
