# Open VibeCoding 0.4.7

这版可以把已有产品文档、研发规范和测试资料接入 Agent 日常任务，也补齐了产品研究、需求交付和测试报告的工具。

- **知识库**支持绑定全局或项目级 Markdown 目录和飞书 Wiki 子目录，按产品、研发、测试三个板块查询。查到资料时可以引用本地行号或飞书原文。新安装从空配置开始。
- **产品研究与交付**支持 App Store 评论采集，以及 ASO、社媒分析和漏斗报告。可以把结构化需求渲染为离线 PRD，并按需求编号合入交互设计。
- **研发辅助**新增 FastAPI 端点和 iOS 功能骨架能力，并支持从评审证据生成代码质量报告。
- **测试与项目质量**支持生成测试用例、导入和执行测试、记录端到端证据与运行项目检查。项目 Skill 统一由多个客户端共享。

```sh
npm install -g https://github.com/mileson/open-vibecoding/releases/download/v0.4.7/open-vibecoding-0.4.7.tgz
open-vibecoding update .
```
