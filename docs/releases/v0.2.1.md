# OpenPrd 0.2.1

## 安装

```bash
npm install -g @openprd/cli@0.2.1
```

## 本次更新

- 移除：OpenPrd 不再提供 `run --context`、`--hook-inject`、ContextCapsule、上下文缓存与全局 session registry。
- 调整：Agent 直接使用宿主会话上下文；UserPromptSubmit hook 只记录提示事件，不再选择、拼接或注入 OpenPrd 上下文。
- 保留：`run --verify`、质量与标准验证、PreToolUse 安全检查、Stop 证据提醒、PRD/change/tasks 和 repo-local 画布绑定继续可用。
- 兼容：旧项目升级时自动移除 manifest 中退役的 `contextCapsule` 格式声明，并刷新 Codex、Claude Code、Cursor 的生成文件。
- 测试：补充 CLI、Hook、manifest 迁移和旧项目 fleet 升级回归。
