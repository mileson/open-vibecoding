# Open VibeCoding 0.4.3

项目需要收款通知时，Agent 可以提供可选飞书卡片模板，并结合现有支付与通知机制完成接入。

- 新增内部最佳实践「收款通知规范与可选模板」，通过研发入口、最佳实践索引与能力目录按场景发现。
- 提供紧凑绿色 Card 2.0 收款卡，包含卡片 JSON、字段合同、独立模板版本及采用说明；金额文本区分浅色和深色模式。
- 用户可以采用模板、调整后采用或保留已有样式。选定后复制到目标项目，后续公共模板更新不覆盖业务项目的定制副本。
- 飞书 CLI 辅助配置与核验，项目后端或已有通知服务负责上线后的发送；工具不附带个人应用、群、凭证或财务服务。
- 通知规范涵盖可信支付事件、持久化去重、失败恢复、币种精度、时区、链接鉴权与消息回读。模板选择不自动授权试发或启用生产通知。

模板和安装逻辑经过静态与自动化回归检查。本次未向飞书发送卡片；具体项目接入后仍需授权试发，并在实际客户端核验渲染与送达。
