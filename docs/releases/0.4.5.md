# Open VibeCoding 0.4.5

Agent 可以把测试用例和执行结果写入 JSON，再用 `open-vibecoding test-report` 生成独立 HTML。报告内置单元、组件、接口／集成与 UI／端到端四种模板，可离线打开。

- `render` 根据用例数据生成报告。筛选按钮显示各状态的用例数，待测试、通过和失败可分别查看。
- `record` 按用例 ID 追加一次执行结果。汇总按最新结果更新，原失败原因和复测证据仍可展开查看。重复提交同一个执行 ID 时只保留一条记录。
- 报告和单次执行都能记录设备型号、操作系统、浏览器及版本。换设备复测时，每次执行保留各自的环境信息。

从 GitHub Release 安装 CLI，然后在已有项目目录运行升级命令。

```sh
npm install -g https://github.com/mileson/open-vibecoding/releases/download/v0.4.5/open-vibecoding-0.4.5.tgz
open-vibecoding update .
```
