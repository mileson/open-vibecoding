# OpenPrd 0.2.0

## 安装

```bash
npm install -g @openprd/cli@0.2.0
```

## 本次更新

- 修复：OpenPrd 不再因需求、评审、变更、任务、说明书或质量证据尚未补齐而阻断用户已经要求的实现、自动任务和发布动作。
- 新增：无人值守自动任务默认进入 automation-safe 模式；除非任务明确启用 OpenPrd，否则不注入上下文，也不要求 OpenPrd 的开发与质量检查。
- 调整：历史 requirement、PRD、review、change、tasks 与实现记录保持冻结；旧功能重新进入当前范围时创建新的需求与变更并关联历史。
- 优化：当前任务、工作区维护、整体就绪声明和具体动作条件分层判断；维护欠账只作提示，真实失败和发布条件仍严格验证。
- 优化：Codex、Claude Code、Cursor 的规则、hooks、CLI 输出和旧项目升级逻辑统一为“用户任务优先、后台材料非阻断”。
