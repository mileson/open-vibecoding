# OpenPrd 0.2.2

## 安装

```bash
npm install -g @openprd/cli@0.2.2
```

## 本次更新

- 新增：头像与单物件 UI 位图的 `transparent-cutout` / `opaque-full-bleed-tile` rendering mode。
- 修复：`preserve-existing` 的圆角、边框、阴影默认只约束 UI 容器，不再被误写进源位图提示词。
- 修复：参考截图不能单独裁决像素合同；生成前检查原始素材或消费组件/CSS，并在 task-scoped `asset-spec.md` 锁定。
- 修复：`.openprd/design/active/` 增加 task scope 边界，旧任务方向与未命名 legacy 内容不再静默污染新任务。
- 验证：新增烘焙圆角底板、full-bleed/透明角错配、旧任务软陶风格污染与生成文案漂移回归。
