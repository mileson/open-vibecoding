# Open VibeCoding 0.4.4

可以让 Agent 为指定模块补单元测试、运行现有测试并给出报告，或者在同一次任务中修复稳定复现的问题并回归。

- 「生成单元测试」按模块的业务规则和边界选择用例，沿用项目已有测试框架和目录。
- 「运行单元测试、报告与修复」记录实际执行结果。要求修复时，保留失败证据，用原用例确认修复，再跑相关回归。

用 GitHub Release 附带的安装包安装 CLI，再在已有项目中运行 `open-vibecoding update .`：

```sh
npm install -g https://github.com/mileson/open-vibecoding/releases/download/v0.4.4/open-vibecoding-0.4.4.tgz
open-vibecoding update .
```
