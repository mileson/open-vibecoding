## 新增需求

### 需求：PM 流程引导与画布评审协同（Human-in-the-loop 升级）
产品经理使用 OpenPrd 时缺少一条看得懂的标准流程指引，经常不知道自己处在需求到收口的哪一步、下一步该做什么；对话协同画布目前是通用白板，没有接入评审方向选择等 OpenPrd 流程环节，Human-in-the-loop 在工具之间断开。

#### 场景：主流程成功
- **当** PM 打开终端或让 Agent 运行 openprd guide，看到 7 步流程和当前位置，按提示进入下一步
- **则** 在 openprd 自身仓库通过单元测试与 standards/quality/run verify；用 Codex CLI 在本地跑一个桌面任务实测新流程效果并留下证据。

#### 场景：边界情况保持可见
- **当** 工作区还没有任何需求版本时 guide 显示第 1 步并给出起步动作
- **则** 产品应保持该情况明确可见，以支持实现和验证

#### 场景：失败模式得到处理
- **当** 方向图片文件缺失时导入跳过该方向并提示，不中断其他方向导入
- **则** 产品应提供有边界且可评审的结果
