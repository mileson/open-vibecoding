## 新增需求

### 需求：去会话追踪化：changes 为真相源 + 人话确认
OpenPrd 画布目前只有单向的“发送给 Codex”整体交接：Agent 不能结构化读取用户在画布上的选区与标注，不能把生成图片精准放回画布锚点旁，标注修改意图靠用户口述或手动截图传递，协同链路断在“人标注完之后”这一步。

#### 场景：主流程成功
- **当** 用户在同一项目开第二个对话窗口，直接读活跃变更清单继续工作，两个窗口状态互不覆盖
- **则** canvas 服务新增 GET /api/selection 与 POST /api/insert-image 且测试通过

#### 场景：边界情况保持可见
- **当** 旧全局 sessions.jsonl 存在时停止写入、保留只读兼容，读取入口平滑降级
- **则** 产品应保持该情况明确可见，以支持实现和验证

#### 场景：失败模式得到处理
- **当** 画布服务未启动时 API 调用失败要提示先运行 openprd canvas
- **则** 产品应提供有边界且可评审的结果
