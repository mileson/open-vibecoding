# Open VibeCoding 工作区

简体中文 | [English](./README_EN.md)

本目录只存放当前任务确实需要的工具配置、设计参考、验证证据和项目知识；Agent 自主判断任务，不经过固定 PRD → change → tasks 流程。

项目级活文档仍位于 `docs/basic/`，按实际代码和产品变化维护。

- `design/`：交互与视觉参考、当前任务的设计合同。
- `benchmarks/`：核验过的参考来源。
- `standards/`：项目文档与代码说明规范。
- `harness/`：当前工具运行与验证证据。
- `quality/`、`learning/`、`knowledge/`：按需生成的质量、学习与知识材料。
- `state/versions/`、`changes/`、`specs/`、`engagements/`：旧项目可能存在的历史材料，只读保留；新项目不会自动创建 PRD、change 或 tasks。

用户明确要求产品文档时，Agent 可直接编写相应交付物。代码变更不以留档为前置条件。版本、设计与外部动作所需证据按实际风险保留。
